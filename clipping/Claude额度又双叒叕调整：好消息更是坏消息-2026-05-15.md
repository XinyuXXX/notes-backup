## 核心变化：6 月 15 日起，用量分家

`claude -p`、Agent SDK 和所有第三方工具（OpenClaw、Conductor 等）的用量，将**不再计入 Claude 订阅常规限额**，改为独立的月度 credit 池。

常规限额继续专用于：Claude Code 交互式使用、Claude Cowork、claude.ai 聊天。

## 月度 Credit 额度

| 套餐 | 月度 credit |
|---|---|
| Pro（$20/月） | $20 |
| Max 5x（$100/月） | $100 |
| Max 20x（$200/月） | $200 |
| Team 标准席位 | $20/席位 |
| Team 高级席位 | $100/席位 |

**覆盖范围**：Claude Agent SDK（Python/TypeScript）、`claude -p`（Claude Code 非交互模式）、Claude Code GitHub Actions、基于 Agent SDK 认证的第三方工具（OpenClaw、Conductor 等）。

> **重要**：需要手动领取。6 月 8 日收到邮件通知，6 月 15 日正式生效。每月重置，不累积。

## 好消息

- `claude -p` 跑批量脚本/Agent SDK 跑自动任务，**不再吃掉 Claude Code 交互额度**——两个预算池互不干扰
- OpenClaw 等第三方工具正式获得 Anthropic 官方认可，被点名为合法的 Agent SDK 使用方式（两个月前 Anthropic 的态度还是"第三方工具去走 API 计费"）

## 坏消息：实际可用量缩水约 10 倍

这 $200 credit 按 **API 零售价**计费。

而之前 `claude -p` / OpenClaw 消耗的是订阅限额——订阅按速率限制控制用量，有大量补贴空间。一个 Max 20x（$200/月）订阅，其实际 token 量折算 API 零售价约为 **$2,000–$5,000+**。

> 如果你之前在 OpenClaw 上用掉了价值 $2,000+ 的额度，现在被压缩到 $200——降了十倍。

Theo Browne（T3 Code 创始人）：「看起来是'多了个预算'，实际上是从大水池变成了小水杯。」

## 影响光谱

- **偶尔跑脚本的轻度用户**：基本利好，白拿额外预算，常规使用完全不受影响
- **重度 `claude -p` 用户**：用量严重降级，$200 可能两天就见底
- **OpenClaw / Conductor 用户**：从之前可能消耗 $2,000+ 等值额度，压缩到 $20–$200 的 credit 池
- **第三方工具开发者**：获得官方认可，但用户在工具上能花的资源缩减一个数量级

## 根本原因

Anthropic 订阅有结构性补贴——交互式场景下人打字速度有天花板，补贴没问题。但 `claude -p` + for 循环可以 24 小时不间断调用，「把本来设计给人类一个月用的额度几个小时跑完」。此次调整本质是**修复定价漏洞**，给一个定额 credit 代替无限补贴。

## 对比：OpenAI Codex 不做拆分

Codex 完全不区分用途，订阅想用什么工具都行。

## 行动项

1. **6 月 8 日**留意 Anthropic 邮件，手动领取 credit（不领 = $0）
2. 评估 OpenClaw 月度实际用量，判断 credit 是否足够
3. 用量大的用户考虑补充 API key 作为备用
