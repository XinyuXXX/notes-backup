## 一、ReAct (Reasoning + Acting)
**最基础、最通用的 Agent 骨架**

**核心逻辑**：思考 → 行动 → 观察 → 再思考 循环
- 思考：分析任务，决定下一步做什么、用什么工具
- 行动：调用工具（搜索、查库、写代码）
- 观察：读取工具返回结果
- 迭代：基于新结果继续推理

**特点**：边想边干、走一步看一步

**适用场景**：
- 实时问答、客服、简单查询
- 动态环境、信息不确定、需要灵活调整
- 要求可解释、可审计（金融、合规）

**代表框架**：LangChain 默认 Agent、AutoGPT 基础版

---

## 二、Reflection / Reflexion（反思模式）
**大模型的"自我检查、二稿优化"**

**核心逻辑**：生成 → 评审 → 修正 → 迭代
1. 先生成初稿
2. 自我批判：找错误、补遗漏、评质量
3. 重写 / 优化，循环 N 轮

**特点**：质量优先、牺牲速度换准确率

**适用场景**：
- 编程、代码生成、数学计算
- 写作、文案、论文润色
- 法律 / 医疗等高精准度任务

**代表框架**：LangGraph 反思循环、GPT-4"自我修正"

---

## 三、Plan-and-Execute（规划-执行）
**复杂长任务的"项目经理模式"**

**核心逻辑**：先定完整计划 → 再分步执行 → 最后汇总
1. Planner：把大任务拆成有序步骤（强模型，调用 1 次）
2. Executor：按计划一步步执行、调用工具（弱模型，调用 N 次）
3. 可选：执行中动态 Replan（重规划）

**特点**：先想全再干、全局视野、不易跑偏

**强弱模型搭配，成本降 70%–90%**

**对比 ReAct**：ReAct 短视、灵活、易绕路；Plan-and-Execute 全局、稳定、适合长流程

**适用场景**：
- 写报告、论文、研究课题
- 多步骤数据分析、代码项目
- 旅行规划、复杂业务流程

**代表框架**：LangGraph 默认推荐、GPT-4

---

## 四、Tool Use（工具调用）
**LLM 连接现实世界的手脚**

**核心逻辑**：
- LLM 不直接做事，而是生成指令 / 代码调用外部能力
- 工具：搜索、API、数据库、文件读写、计算器、浏览器

**2026 主流形态**：
- Code Interpreter 模式：写 Python 代码执行（更安全、可审计）
- Function Calling：结构化调用预定义函数

**适用场景**：
- 所有需要联网、查数据、做操作的任务
- RAG、数据分析、自动化办公

**代表**：ChatGPT Code Interpreter、Claude Artifacts

---

## 五、Multi-Agent Collaboration（多智能体协作）
**AI 团队协作：专家分工**

**核心逻辑**：
- 多个 Agent 扮演不同角色（产品、开发、测试、设计、审稿）
- 对话协作、互相补充、互相评审

**常见架构**：
- 中枢-辐射：一个主管 Agent 分配任务
- 对等协商：多 Agent 自由讨论达成共识

**数据支持**（Andrew Ng / Du et al., 2023 Multiagent Debate）：
| Task | Single agent | Multi-agent |
|---|---|---|
| Biographies | 66.0% | **73.8%** |
| MMLU | 63.9% | **71.1%** |
| Chess move | 29.3% | **45.2%** |

**适用场景**：
- 软件开发、内容创作团队
- 复杂案件分析、跨领域决策
- 模拟会议、辩论、评审

**代表框架**：AutoGen、ChatDev、LangGraph 多节点

---

## 六、Hierarchical Agent（层级化 / 中枢式）
**大企业式架构：中枢指挥 + 分层执行**

**核心逻辑**：
- 顶层中枢：做全局决策、目标拆解
- 中层 Agent：负责子任务、协调工具
- 底层执行器：具体操作、调用 API

**特点**：可控性强、复杂系统稳定、易维护

**适用场景**：
- 企业级业务自动化
- 大型系统运维、机器人控制
- 高可靠性、强监管场景

---

## 七、2026 主流混合模式（实战必用）

实际项目很少只用一种，通常是**组合**：

1. **ReAct + Reflection**：边做边反思，每步自我检查
2. **Plan-and-Execute + Reflection**：先规划 → 执行中反思修正 → 重规划
3. **Multi-Agent + ReAct/Plan**：团队内每个 Agent 用 ReAct 或 Plan 模式
4. **Supervisor-Worker**：监督者（评审）+ 工作者（执行）

## 一句话选型速记

| 场景 | 范式 |
|---|---|
| 简单动态任务 | ReAct |
| 高质量写作 / 代码 | Reflection |
| 长流程 / 多步骤项目 | Plan-and-Execute |
| 联网 / 操作 / 计算 | Tool Use |
| 复杂团队 / 多角色 | Multi-Agent |
| 企业级稳定可控 | Hierarchical |
