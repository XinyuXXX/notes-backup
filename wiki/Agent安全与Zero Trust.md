## 主题概要

AI Agent 引入了自主性、工具访问和多 Agent 协作，使传统边界安全彻底失效。威胁面的核心变化：AI 正把漏洞到利用的时间从几个月压缩到几小时，且 Agent 可以滥用**合法权限**——传统访问控制对此无能为力。Zero Trust 的核心——永不信任、假设已被攻破、最小权限——提供了 Agent 安全的持久框架。Anthropic 的白皮书给出了六大能力域（三级路线图）+ 八步实施工作流 + 防御运营指引。

## 核心概念

- **Zero Trust 三原则**：① 永远不信任、始终验证（内网和外部请求同等审查）；② 假设已被攻破（精力放在限制损害，而非防止入侵，按身份分段）；③ 最小权限（控制爆炸半径）。
- **设计检验：不可能 vs 麻烦**：评估控制措施时问：这是让攻击变得不可能，还是只是更麻烦？价值来自摩擦（速率限制、非标端口、短信 MFA）的控制，在 Agent 化攻击者面前大幅失效（无限耐心 + 近零成本）。优先选择**移除能力**的控制，而非限流能力的控制。
- **爆炸半径（Blast Radius）**：出问题时的潜在损害范围。只读单个 DB 的 Agent vs. 有云管理员权限的 Agent，安全投入应匹配暴露程度。
- **最小代理权（Least Agency）**：OWASP 新术语，把最小权限延伸到 Agent 应用层。不只约束访问什么，还限制工具能做什么、多频繁、在哪里。（示例：数据库工具只拿只读查询权限；邮件摘要工具无发送/删除权限）
- **AI 加速攻防**：前沿 AI 把漏洞到利用时间从几个月压缩到几小时，边际成本按美元计。基本功扎实（AI 辅助扫描找不到 bug）+ 从第一天按"假设已被攻破"设计，比"AI 最先进"更能赢。
- **间接提示注入**：攻击者把恶意指令嵌入 Agent 会处理的外部数据（网页、邮件）。**LLM 无法可靠区分信息性上下文和可执行指令**（Microsoft Research 确认）。用户永远看不到恶意载荷，Agent 把它当合法请求执行。聚光灯技术（Spotlighting）将此攻击成功率从 >50% 降到 <2%。
- **工具链攻击**：骗 Agent 把合法工具以有害顺序组合（如 CRM + 邮件工具窃取客户数据）。每条命令通过可信二进制文件在有效凭证下执行，主机端监控看不到恶意软件。传统访问控制对此无效。
- **困惑代理人（Confused Deputy）**：被攻破的低权限 Agent 向高权限 Agent 转发看似合法指令，后者直接执行未验证原始用户意图。多 Agent 场景下放大。解法：Agent 接受委派任务前验证对方身份和授权。
- **记忆投毒的持久性**：植入 Agent 记忆的恶意指令危害当前和**所有未来会话**。长期记忆漂移更微妙：摘要或同伴 Agent 的反馈逐步偏移存储知识，无单个改变看起来恶意，难以检测。防御：TTL 自动过期 + 上下文完整性哈希验证（存储在防篡改日志中，分离于记忆内容）。
- **模型后门难以消除**：Anthropic 研究：只需 250 个恶意文档就能在 6 亿到 130 亿参数 LLM 中植入后门，且后门在 SFT + RLHF 安全训练后仍然存在。
- **Agentic SOAR**：下一代安全编排平台，增加对新情况的自适应能力，在几秒内应对 AI 驱动攻击。当前 SOAR 只协调工具；Agentic SOAR 自适应应对。**自动化事务性工作，不自动化决策**——模型做笔记/证据/事后报告，人类做遏制/披露/客户沟通决策。
- **三级实施路线图（Foundation / Enterprise / Advanced）**：AI 已经抬高了 Foundation 的地板：短命 token、密码学身份、基于身份的隔离和自动化初步分诊现在是**入门要求**，不是愿景。静态 API 密钥在 Foundation 级别不是合法入口。
